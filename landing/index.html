Yes! MicMorph supports both macOS (Apple Silicon & Intel) and Windows 10/11 (64-bit). On macOS it uses BlackHole, and on Windows it uses VB-Audio Virtual Cable. Both run 100% locally with zero latency.

Not at all. MicMorph uses less than 2% CPU. It runs as a lightweight background process in your menu bar and has zero impact on your system performance or call quality.

BlackHole is a free, open-source virtual audio driver for macOS. It creates an invisible "bridge" that lets MicMorph send your transformed voice to any app. It's a one-time install via Homebrew and requires a restart.
