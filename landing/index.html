Opening MicMorph on macOS

Simple step-by-step setup guide

⚡ Recommended: 1-Click Fast Install
Zero Security Prompts

Skip manual Gatekeeper steps by running this 1-line command in Mac Terminal:

$ curl -fsSL https://micmorph.work/install.sh | bash
Or Manual .dmg Setup Steps
1
Drag MicMorph to Applications
Open the downloaded MicMorph_0.1.0_aarch64.dmg file, then drag the MicMorph app icon into your Applications folder.
2
First Launch: Right-Click ➔ Open
In your Applications folder, Right-Click (or Control-click) MicMorph and choose Open, then click "Open" in the dialog. 💡 Right-clicking allows macOS to open unsigned indie software without blocking.
3
If Blocked ("Unverified Developer")
If macOS still prevents opening: go to System Settings ➔ Privacy & Security, scroll down to the Security section, and click "Open Anyway".
4
One-Click Audio Bridge Setup
When MicMorph launches, click the orange "⚡ Install Audio Bridge" button. Then in Google Meet, Zoom, or Slack, select "MicMorph" as your microphone!
ℹ️ Why does macOS display this?
MicMorph is a 100% free indie tool in early access. Because we haven't paid Apple's $99/year developer fee yet, macOS Gatekeeper displays a standard security verification on first launch only.
